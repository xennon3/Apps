Serial Scope Lite

1. Unzip this whole folder somewhere (e.g. Documents or the Desktop).
2. Close Tera Term (only one program can use the COM port at a time).
3. Double-click "Serial Scope.exe". It opens in its own window using Microsoft Edge.
4. Click Connect and pick the Moxa port (e.g. "MOXA USB Serial Port (COM3)").

Keep "Serial Scope.exe" and index.html together in the same folder.
Windows may warn about an unknown publisher the first time: click More info -> Run anyway.
